## Projetos em destaque

### [API-PTF](https://github.com/VitorCamprubi/API-PTF) — API de transações financeiras

Estudo prático de padrões comuns em sistemas transacionais: idempotência persistida com lock por chave, Transactional Outbox para consistência entre banco e fila, processamento assíncrono com retry e DLQ no RabbitMQ, e lock pessimista no saldo para evitar lost update.

**Stack:** Java 21, Spring Boot 3, PostgreSQL, Flyway, RabbitMQ, Testcontainers, Prometheus.

### [OMS-Lite](https://github.com/VitorCamprubi/OMS-Lite) — API de gestão de pedidos

API REST com clientes, produtos, controle de estoque e criação transacional de pedidos. Foco em separação de camadas e regras de negócio claras.

**Stack:** Java, Spring Boot, JPA/Hibernate, MySQL, Maven.

### [SGTC](https://github.com/VitorCamprubi/sgtc) — Trabalho de Graduação

Trabalho de graduação (Tecnólogo em GTI): aplicação full stack para gerenciar grupos de TCC, orientadores, versões de documentos e reuniões.

**Stack:** Spring Boot, Spring Security + JWT, JPA, MySQL, Angular, Docker Compose.
