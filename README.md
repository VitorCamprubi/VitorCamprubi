## 📌 Projetos em destaque

### 🎓 SGTC — Sistema de Gerenciamento de Trabalhos Científicos

Sistema web full stack desenvolvido para centralizar a gestão de Trabalhos de Graduação, permitindo o controle de grupos, orientadores, alunos, documentos, comentários e reuniões.

**Tecnologias utilizadas:**

Java, Spring Boot, Spring Security, JWT, JPA/Hibernate, MySQL, Angular, Docker e Maven.

**Principais funcionalidades:**

- Autenticação com JWT
- Controle de acesso por perfis
- Gestão de grupos acadêmicos
- Associação de alunos, orientadores e coorientadores
- Upload e controle de versões de documentos
- Comentários em documentos
- Registro de reuniões
- Integração entre backend Java e frontend Angular
- Ambiente local com Docker Compose

🔗 Repositório: [github.com/VitorCamprubi/sgtc](https://github.com/VitorCamprubi/sgtc)

### 📦 OMS-Lite — Order Management System

API REST desenvolvida para simular um fluxo de pedidos, clientes, produtos e controle de estoque, aplicando regras de negócio comuns em sistemas backend.

**Tecnologias utilizadas:**

Java, Spring Boot, JPA/Hibernate, MySQL, Maven e arquitetura em camadas.

**Principais regras de negócio:**

- O pedido só é criado se o cliente existir
- O produto precisa ter estoque suficiente
- O estoque é baixado automaticamente ao confirmar o pedido
- O total do pedido é calculado com base nos itens
- A criação do pedido ocorre dentro de uma transação
- Separação de responsabilidades entre Controller, Service, Repository e Domain

🔗 Repositório: [github.com/VitorCamprubi/OMS-Lite](https://github.com/VitorCamprubi/OMS-Lite)
